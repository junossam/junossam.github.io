# 알고리즘 실습실
> 파이썬 이해, 알고리즘 이해, 자료구조 이해와 관련된 다양한 학습 페이지를 모아둔 공간입니다.

이 저장소는 수업과 자기주도 학습에 활용할 수 있도록 만든 웹 기반 실습 자료 모음입니다.  
각 페이지에서는 개념 설명에 그치지 않고, 직접 눌러 보고 실행해 보면서 내용을 이해할 수 있도록 구성했습니다.

## 주요 내용
- 파이썬 개념 이해
- 알고리즘 원리 이해
- 자료구조 개념 이해
- 시각화 기반 학습 페이지 제공
- 실습형 웹 콘텐츠 지속 추가

## 바로가기
- 메인 페이지: https://junossam.github.io/algo-lab/
