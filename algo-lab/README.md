# 알고리즘 실습실
> 탐색과 정렬 알고리즘을 직접 만들고 비교해보는 공간

이 파일만 수정하면 `index.html`이 자동으로 최신 내용을 읽어 화면에 반영합니다.

## 사용 방법
1. 아래 `###` 블록 하나가 카드 1개입니다.
2. 새 페이지를 추가하려면 같은 형식으로 블록을 하나 더 복사해 넣으면 됩니다.
3. `파일명`에는 실제 열릴 html 파일명을 적습니다.
4. `용도`는 카드 설명으로 표시됩니다.
5. `태그`는 선택 사항입니다.

---

### 정렬 알고리즘 만들기
- 파일명: sort-builder.html
- 용도: 정렬 과정을 직접 구현하고 확인
- 태그: 정렬, 구현, 기초

### 정렬 알고리즘 비교
- 파일명: sort-performance.html
- 용도: 속도와 효율성을 비교
- 태그: 정렬, 비교, 성능

### 탐색 알고리즘 만들기
- 파일명: search-builder.html
- 용도: 순차 탐색과 이진 탐색 과정을 이해
- 태그: 탐색, 구현, 기초

### 탐색 알고리즘 비교
- 파일명: search-performance.html
- 용도: 탐색 횟수와 성능을 분석
- 태그: 탐색, 비교, 성능

### 리스트와 집합 비교
- 파일명: List-set-comparison-page.html
- 용도: 리스트와 집합의 차이를 시각적으로 비교
- 태그: 자료구조, 비교

### 파이썬 자료형 메모리
- 파일명: python_type_memory.html
- 용도: 자료형에 따라 메모리에 저장되는 방식을 시각적으로 확인
- 태그: 파이썬, 메모리, 자료형
