이중 연결 리스트 탐색, 삽입, 삭제의 작동 원리 이해하기

이중 연결 리스트는 노드를 옮기지 않고 prev 주소와 next 주소를 바꾸어 연결을 변경합니다. 즉 메모리 슬롯은 그대로 두고, 앞뒤 연결만 수정합니다.

삽입은 드래그 앤 드롭뿐 아니라 삽입 노드 값 클릭 → 왼쪽 노드 next 주소 칸 클릭 → 삽입 노드 값 클릭 → 오른쪽 노드 prev 주소 칸 클릭으로도 할 수 있습니다.
삭제도 삭제 노드 값 클릭 → 이전 노드 next 주소 칸 클릭 / 다음 노드 prev 주소 칸 클릭 방식으로 작동합니다.
